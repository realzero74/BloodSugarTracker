# 애플리케이션 개발 명세서 (Application Specification)

## 1. 개요 (Overview)
- **앱 이름:** (가칭) Blood Sugar Tracker
- **목적:** 사용자가 측정 직후 혈당을 쉽고 빠르게 기록하고, 누적된 데이터를 직관적인 그래프로 파악할 수 있도록 돕는 혈당 관리 앱
- **타겟 플랫폼:** Android 또는 Windows 앱 (추후 확정)
- **타겟 사용자:** 당뇨 환자 및 일상적으로 혈당 관리가 필요한 분들

## 2. 주요 기능 (Core Features)
- **혈당 간편 기록:** 
  - 수치 입력만으로 즉시 저장 가능 (최소 필수값)
  - 부가 정보(선택): 측정 시간(기본값은 현재 시간), 상태 태그(공복/식전/식후 등), 간단한 메모 기록
- **혈당 데이터 시각화 (대시보드):** 
  - 최근 30일간의 측정 데이터를 상태 태그(공복, 식전, 식후)별로 구분하여 3개의 그래프 라인으로 시각화 (가로 스크롤 지원, 스크롤 시 좌측 Y축 수치 고정, 진입 ��� 최신 데이터(우측 끝)로 자동 스크롤)
  - 사용자가 원하는 상태 태그만 선택하여 볼 수 있도록 필터링(토글) 버튼 제공
  - 최근 30일간의 전체 평균 혈당 수치를 그래프 내 가로선(기준선)으로 표시하여 직관적인 파악 제공
- **기록 목록 및 페이징:**
  - 대시보드 화면에서는 가장 최근 측정한 기록 3개만 요약 표시
  - 전체 기록을 볼 수 있는 별도의 화면(또는 모달)을 제공하며, 대시보드의 목록과 동일한 포맷으로 기기 화면 길이에 맞춰 유연하게 한 페이지당 개수를 자동 조정하여 페이징(Pagination) 처리 (세로 스크롤 발생 방지)

## 3. UI/UX 디자인 및 화면 구성 (UI/UX Design)
> 화면 UI는 `../sample-ui` 폴더 내에 순수 HTML/CSS/JS로 프로토타입을 제작하여 캡처(이미지) 형태로 확인 및 검증합니다.
- **화면 구조 및 플로우:**
  1. **홈/대시보드 (기본 화면):** 앱 실행 시 가장 먼저 보이며, 상단에 혈당 추이 그래프(가로 스크롤), 하���에 최근 기록 3개가 표시됩니다. 화면 우측 하단에 플로팅 버튼(➕)을 배치합니다.
  2. **혈당 입력 (모달/팝업):** 플로팅 버튼(➕) 클릭 시 혈당을 입력할 수 있는 팝업(또는 바텀 시트)이 등장합니다.
  3. **전체 기록 화면 (History):** 대시보드 하단의 '전체보기'를 누르면 나타나며, 과거의 모든 기록을 페이지별로 탐색할 수 있습니다.
